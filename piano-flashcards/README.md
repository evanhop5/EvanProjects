# 🎹 Note Quest

A simple, fun flash-card app for learning to read music, matched to
**Alfred's Premier Piano Course, Level 1A** (Theory & Performance).
Built for iPhone, and it works in any browser. It's a single page with
no account, no ads, and nothing to install.

## What it practices

| Mode | What it covers |
|---|---|
| 🎼 Treble Notes | Right-hand C position (Middle C – G), including landmark Treble G |
| 🎵 Bass Notes | Left-hand C position (Bass C – G), Bass F, Middle C |
| 🎹 Piano Keys | Naming white keys using the 2- and 3-black-key groups |
| 🥁 Rhythm | Quarter, half, dotted half, and whole notes, plus rests |
| 🦘 Steps & Skips | Step, skip, or repeat |
| ✨ Music Signs | Clefs, bar line, double bar, repeat sign, 4/4 and 3/4, p / mp / mf / f |

Each round has 10 cards. A correct answer earns 10 pts, with a +5 bonus once you get 3 in a row
and +50 for a perfect round. Rounds earn 1–3 ⭐, and points unlock ranks
(Beginner 🌱 → Grand Legend 🐉). A 🔥 day streak counts the days in a row you practice.
Scores are saved on the device.

## Put it on the iPhone home screen

1. Host this folder anywhere static, for example with GitHub Pages:
   **Settings → Pages → Deploy from branch**, then open
   `https://<user>.github.io/<repo>/piano-flashcards/`.
2. Open the link in **Safari**, tap **Share → Add to Home Screen**.
3. It launches full-screen like an app.

Tip: the iPhone's silent switch mutes web sounds, so flip it off to hear the notes.

Music symbols are drawn from the open-source Noto Music font (SIL Open Font License).
